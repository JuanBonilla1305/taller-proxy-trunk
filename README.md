# Taller Proxy en el Trunk

Guía del taller: patrón **Proxy** + **Trunk-Based Development** (Java 17 + JUnit 5), en parejas, 90 minutos.

La página se publica automáticamente con GitHub Pages en cada push a `main`.

## Para los estudiantes

Abre el enlace de GitHub Pages del repositorio y sigue los pasos del 0 al 6.

## Para editar

El contenido vive en `index.html`. Cualquier cambio en `main` se despliega solo
mediante el workflow `.github/workflows/deploy.yml`.
